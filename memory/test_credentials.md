# Test Credentials

## Login Credentials
The app now requires authentication. Use any email and password (minimum 6 characters) to log in.

**Example Test Account:**
- Email: `test@example.com`
- Password: `password123`

## Notes
- Authentication is simulated (demo mode) - any valid-looking email and 6+ character password will work
- Upon login, the user gets assigned demo memberships to test the RBAC features
- The user's display name is derived from the email prefix

## Role-Based Access
- After login, users are assigned as "admin" of "Gold Savings Circle" (circle-1)
- Users are assigned as "member" of "Family Fund" (circle-2) and "Emergency Pool" (circle-3)
