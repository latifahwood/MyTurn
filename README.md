# MyTurn

A modern fintech application designed to digitize Caribbean rotating savings groups (commonly known as “meeting turns” or tontines).

MyTurn enables users to create savings circles, track contributions, enforce accountability through late fees, and manage payouts in a transparent and structured way.


## Overview

Traditional savings groups are often managed informally through chats or spreadsheets, leading to missed payments, confusion, and lack of trust.

MyTurn solves this by providing:
- Clear payment tracking
- Structured group management
- Automated reminders
- Transparent contribution history


## Features

### Authentication
- User sign up and login
- Secure user-based access to circles

### Circle Management
- Create savings circles
- Invite members via private invite links/codes
- Join circles securely

### Payments
- Track contributions per user
- Late fee system with configurable rules
- Payment confirmation flow

### Payment History
- View all past transactions
- Status tracking:
- Paid
- Pending
- Late

### Notifications & Reminders
- Payment due alerts
- Overdue notifications
- Payout updates

### Role-Based Access
- Admin (circle creator) permissions
- Member-level access restrictions


## Key Concepts

MyTurn is built around a trust-based financial system where:
- Users contribute regularly to a shared pool
- Each member receives a payout in a rotating order
- Payment behavior is tracked to ensure accountability
